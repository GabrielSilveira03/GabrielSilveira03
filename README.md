## Projetos em destaque

**MedControl** *(repositório privado — estágio)*
Plataforma web para gerenciaremento de produção médica (consultas, procedimentos, plantões), especialmente médicos especialistas, cadastro de médicos com regras de pagamento e prestação de contas, com dashboards para o setor administrativo e para cada médico.
Stack: React, TypeScript, Vite, Tailwind CSS, Supabase (PostgreSQL), TanStack Query, Vitest
Contexto: desenvolvido em equipe, no ambiente de trabalho (estágio)
Resultado: substituiu o controle por planilhas Excel (sujeitas a retrabalho e inconsistência) por um sistema centralizado, reduzindo retrabalho e otimizando tempo

**BoraPalpitar** *(repositório privado — pessoal)*
Plataforma para criação e gestão automatizada de bolões esportivos, com digitalização de cartelas físicas via IA (OCR) e sincronização de campeonatos em tempo real.
Stack: React, TypeScript, Node.js/Express, Supabase (PostgreSQL), Google Gemini AI (fallback Mistral), Football-Data.org API
Contexto: projeto pessoal, desenvolvido sozinho
Resultado: automatizou um processo antes manual (conferência de cartelas físicas e montagem manual dos resultados), digitalizando e otimizando todo o fluxo do bolão

**Backend Sistema Irrigacao Integrado OpenAI**
API para gerenciamento de lavouras, sensores e controle de água, usando IA (OpenAI) para diagnosticar eficiência da irrigação e gerar recomendações agrícolas.
Stack: Node.js, Express, PostgreSQL + Prisma, Docker, OpenAI API (gpt-4o-mini)
Contexto: projeto acadêmico em trio (UFC Sobral, disciplina de Tecnologias Web II)
Resultado esperado: automatizar o diagnóstico de eficiência da irrigação a partir dos dados dos sensores, reduzindo a análise manual

**Plataforma de Apoio Psicológico Comunitário**
Solução web que conecta profissionais de psicologia a pessoas que precisam de apoio emocional, facilitando o acesso a atendimentos gratuitos ou de baixo custo.
Stack: React, Node.js, Express, PostgreSQL + Prisma, JWT
Contexto: projeto de curso, em equipe
Resultado esperado: centralizar cadastro, anamnese e evolução clínica dos pacientes num único fluxo digital
